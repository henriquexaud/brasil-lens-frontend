# Cores do mapa

As cores do mapa representam condições climáticas e ambientais. Temperatura e precipitação usam escalas contínuas com faixas de legenda próprias; alertas usam cores por severidade; focos de calor e hidrografia têm simbologia dedicada.

As cores territoriais de base mantêm contraste suficiente para distinguir divisas, seleção e estados sem preenchimento temático. A ausência de observações usa um tom neutro.
